Data interpretation
Community reports are stored immediately, then move through Pending → Verified → Resolved in the Control Room.
Weather and marine panels are model data. They are not official emergency alerts or navigation advice.
Live vessel sharing is opt-in. The browser asks for location permission and the map hides stale positions after the cutoff.
Zero-cost stack: Leaflet + OpenStreetMap, Open-Meteo and Render Free. No Google Maps JavaScript API key is required.
